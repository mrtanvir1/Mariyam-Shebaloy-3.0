বর্তমান তথ্য:

Disease Templates

এখানে শুধু আপনার নিজের clinically verified template সংরক্ষণ করুন। এই সিস্টেম নিজে থেকে কোনো রোগের জন্য ওষুধ নির্বাচন বা dose নির্ধারণ করে না। Template ব্যবহার করার পর prescription দেওয়ার আগে প্রতিটি medicine, frequency, food instruction ও duration নিজে review করবেন।

Template Medicines

Saved Templates

Backup & Restore

Patient, Visit, Medicine এবং Disease Template—সব data এই ফোনের browser Local Storage-এ থাকে। ফোন reset বা browser/app data clear হলে Local Storage মুছে যেতে পারে। তাই নিয়মিত backup রাখুন।

📦 Full Backup

সব Patient + Visit + Medicine + Disease Template একসাথে একটি JSON backup file হিসেবে সংরক্ষণ করুন।

📥 Restore

আগে তৈরি করা backup JSON file নির্বাচন করুন। Restore করলে বর্তমান data-এর সাথে backup data merge হবে; একই ID থাকলে backup-এর তথ্য ব্যবহার করা হবে।

👤 Patient File

একজন রোগীর সম্পূর্ণ profile + সব visit একটি আলাদা JSON file হিসেবে File Manager-এ save করতে পারবেন। নতুন ফোনে বা data হারালে একই file import করে রোগী ফিরিয়ে আনতে পারবেন।


⚠️ Data Management

এটি করলে Local Storage-এর সব patient, visit, medicine ও template মুছে যাবে। Backup না থাকলে ফিরিয়ে আনা যাবে না।
