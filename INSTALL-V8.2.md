# Mariyam Shebaloy V8.2

Replace the previous `v8-patch.js` with this version. Keep your existing `index.html`, `config.js`, Supabase setup, Dashboard, Profile, medicines and other files unchanged.

V8.2 adds the missing medicine **প্রয়োজন অনুযায়ী / PRN** option to both New Patient and New Visit prescriptions.

Options:
- প্রয়োজন অনুযায়ী (PRN)
- ব্যথা থাকলে খাবেন
- জ্বর হলে খাবেন
- নিজের নির্দেশনা

The selected instruction is saved with the medicine and shown on the printed prescription.
